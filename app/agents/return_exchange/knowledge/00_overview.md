## Return & Exchange Overview

Return Co-pilot covers reverse logistics and exchange workflows: request lookup, status, refund/reversal diagnosis, config Q&A, ops triage, and exchange catalogue browse.

### Capabilities
- Find return/exchange by reference number / AWB / order ID
- Explain current status from feed + item status + return/refund logs
- Diagnose stuck refunds via payment reversal info (read-only)
- Answer what is enabled: windows, refund mode, rejection, warehouse, QC
- Suggest manual next steps in the dashboard

### Not in scope
- Create / update / recreate requests
- Retry payment reversal, regenerate labels
- Convert return ↔ exchange
- Change any R&E config
- Any POST / PUT / PATCH / DELETE through tools
